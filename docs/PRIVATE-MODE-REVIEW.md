# Current privacy and recovery review

The current review is [SUB-WALLETS.md](SUB-WALLETS.md). It covers all three sub-wallets, both Neptune address types, optional messages, disclosure limits, confirmation-based automatic refresh, seed-only recovery and performance tradeoffs. The current wire description is [PRIVATE-NOTIFICATIONS.md](PRIVATE-NOTIFICATIONS.md).

The earlier shared-balance Private controls menu, automatic rotation switch and self-hosted payment URL proposal have been superseded. This version has distinct balances and change branches, Standard by default, and optional sub-wallet creation on request. It uses no address-distribution service and performs no automatic mixing.
